# Workstation Control Dashboard (`apps/dashboard`)

Next.js 14 & Tailwind CSS control panel for the **Personal Local AI Workstation**.

## Features
- Real-time environment binary status monitor (`node`, `python`, `cargo`, `docker`, `ollama`).
- Local LLM endpoint router health status & offline fallback display.
- Swarm routing monitor and workspace module status.

## Development
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the workstation control center.
